かつしかエコ助成金の完了報告の最終提出期限は、2027年12月28日（必着）です。書類は、手引きの一覧で太陽光が7点、蓄電池が6点あります。この記事では、2026年10月2日に確認した葛飾区の公式情報をもとに、期限と書類を、工事の前から頼んでおくことと合わせて整理します。

## 期限は二つの日付で考える

完了報告は、工事が終わってから出す手続きです。その前に事前協議があります。葛飾区の案内では、原則として工事着工の4週間前までに事前協議が必要です。区から郵送される事前協議回答書が届いてから設置工事に入ります。回答書より前に着工すると、助成の対象外です。

完了報告の期限は、次の二つが別々に書かれています（2026年10月2日時点の葛飾区の公式情報）。

| 項目 | 内容 |
| --- | --- |
| 最終提出期限 | 2027年12月28日（必着） |
| 提出の前提条件 | 工事完了後3か月以内に、領収書など必要書類をそろえて、設置完了報告書兼助成金交付申請書とともに提出する |
| 郵送の場合の受付日 | 区に届いた日 |

工事の完了日から3か月後の日と、2027年12月28日を、カレンダーの両方に書き込んでおくと確かめやすくなります。期限内に出すことを前提に、早めに準備してください。制度の全体は[葛飾区の補助金のページ](/subsidy/katsushika)、工事までの段取りは[導入までの流れ](/flow)で確認できます。

## 太陽光の完了報告で出す書類7点

葛飾区の太陽光発電システム手引き（個人住宅）にある、完了報告時の書類は次の7点です。

1. 完了報告書兼助成金交付申請書（第5-1号様式）
2. 交付請求書（第8号様式）
3. 振込口座が確認できる書類の写し
4. 領収書と、その内訳がわかる請求書または内訳書の写し
5. 施工後のカラー写真（パネルの枚数が確認できるもの）
6. 居住確認書類
7. 電力会社との接続契約のご案内（契約者が申請者と同一であること）

5番は、パネルの枚数が写真で確認できることが条件です。7番は、契約者の名前が申請者と同じかどうかを、提出前に見ておきます。既設の蓄電池やHEMSがあり、併設加算を申し込む場合は、設置状況がわかる写真などを追加で提出します。

## 蓄電池の完了報告で出す書類6点と、太陽光との違い

葛飾区の蓄電池手引き（個人住宅）にある、完了報告時の書類は6点です。完了報告書兼助成金交付申請書、交付請求書、振込口座が確認できる書類の写し、領収書と内訳がわかる請求書または内訳書の写し、施工後のカラー写真、居住確認書類です。

既設の太陽光があり、併設加算を申し込む場合は、電力会社が発行した、売電していることを確認できる書類の写しを追加します。発行から3か月以内のものです。太陽光との違いを表にまとめます。

| 項目 | 太陽光 | 蓄電池 |
| --- | --- | --- |
| 書類の点数 | 7点 | 6点 |
| 施工後の写真 | パネルの枚数が確認できるもの | 全景と、型番がわかる蓄電池ユニット |
| 電力会社との接続契約のご案内 | 一覧にある（契約者は申請者と同一） | 一覧にない |
| 併設加算の追加書類 | 既設の蓄電池・HEMSの設置状況がわかる写真など | 既設太陽光の売電確認書類の写し（発行3か月以内） |

蓄電池の写真には、型番がわかるユニットの撮影が含まれます。

## 工事の前に施工業者へ頼んでおくこと

契約の段階で、次の点を施工業者に伝えて、確認しておきましょう。

| 書類 | 工事前に確認すること |
| --- | --- |
| 施工後の写真（太陽光） | パネルの枚数が確認できる撮り方になっているか |
| 施工後の写真（蓄電池） | 全景と、型番がわかるユニットの写真を撮るか |
| 領収書 | 宛名が申請者になっているか。内訳がわかる請求書または内訳書が付くか |
| 接続契約のご案内（太陽光） | 契約者が申請者と同一になっているか |

あわせて、事前協議の段取りも聞いておきます。区は、助成対象設備の導入前に事前協議書を提出しなければならないという要件に反した手続代行者・施工業者を、かつしかエコ助成金の対象外にする措置をとり、公式サイトで公表しています。措置の内容は、区の公式ページで確認できます。区の案内では、施工業者は区内・区外を問いません。

## 名義・日付・支払い方法の決まり

書類の中身以外にも、区の案内に決まりがあります。完了報告で確かめたい日付・名義・支払い方法などの決まりを、表にまとめます。

| 項目 | 葛飾区の案内 |
| --- | --- |
| 日付 | 完了報告書兼助成金交付申請書と請求書の日付は、未記入で提出する（よくあるご質問） |
| 名義 | 申請者、建物居住者、領収書の名義人、助成金の振込名義人が同じ人であること。申請者と請求者も同じ人 |
| カード・ローンで支払う場合 | 領収書を提出する。ローンの場合は、ローンの契約明細書でも対応できる。所有権が申請者にあることが条件 |
| 証明書類 | 役所などが発行する書類は、発行後3か月以内のもの |
| 提出した書類 | 返却されない |

日付は自分で入れず、まず空欄のままにしておきます。工事の代金を支払う前に、宛名を申請者の名前にそろえておきましょう。提出した書類は返ってこないので、手元に残したい書類は、出す前に写しを取っておいてください。

## 提出前の最終確認と出し方

区のよくあるご質問では、書類は施工業者など代理の人が窓口へ持参してもよく、郵送でも受け付けるとされています。区の公式ページでは、混雑緩和のため郵送での申請が勧められています。郵送の場合は、区に届いた日が受付日です。最終提出期限は必着なので、2027年12月28日までに区へ届くようにします。

出す前に、次の点を一覧と照らし合わせてください。

- 太陽光は7点、蓄電池は6点がそろっているか
- 併設加算を申し込む場合の追加書類が入っているか
- 写真に、パネルの枚数、または蓄電池の型番が写っているか
- 領収書の名義が、申請者と同じか
- 役所などが発行する書類が、発行後3か月以内か
- 工事完了後3か月以内と、2027年12月28日の両方に間に合うか
