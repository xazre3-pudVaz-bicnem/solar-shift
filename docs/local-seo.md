# 地域の検索（ローカル SEO・MEO）の方針

「葛飾区 太陽光 業者」「葛飾区 蓄電池」のような、地域の名前を含む検索と、Google マップの検索で選ばれるための方針。
サイトの側でできることは実装済み。Google ビジネス プロフィール（以下 GBP）の設定は、運営者が管理画面で行う（コードからは触らない）。

最終確認：2026-11-04

## 1. 名称・所在地・電話（NAP）

サイト・GBP・会社のサイト・SNS・取引先の掲載で、一字一句そろえる。サイトの側は `lib/site.ts` の1か所から出している。

| 項目 | 表記 |
| --- | --- |
| 名称 | SOLAR SHIFT（ソーラーシフト） |
| 運営会社 | 株式会社サイプレス |
| 所在地 | 〒125-0061 東京都葛飾区亀有3丁目16-14-201 |
| 電話 | 090-2360-0052 |
| 営業時間 | 9:00〜20:00（定休日なし） |
| URL | https://www.solarshift.jp/ |

- 2026-11-04 に、運営会社のサイト（https://www.cypress-all.co.jp/）の所在地が「〒125-0061 東京都葛飾区亀有3-16-14-201」であることを確かめ、このサイトの表記を「亀有3丁目16-14-201」にそろえた（部屋番号を足した）。
- 「3丁目16-14」と「3-16-14」は同じ住所の書き方の違い。GBP は、Google の住所入力で出る表記のままでよい。
- 変えるときは、`lib/site.ts` と `docs/VERIFIED_FACTS.md` の両方を直す。

## 2. GBP のウェブサイトの欄に入れる URL

**おすすめ：ウェブサイトの欄は TOP（`https://www.solarshift.jp/`）、予約・問い合わせの欄は `https://www.solarshift.jp/contact`。**

| 候補 | 判断 |
| --- | --- |
| TOP `/` | **採用**。事業の全体（サービス・対応エリア・補助金・会社情報）が1ページで分かり、構造化データの LocalBusiness・Organization の `url` も TOP。GBP と同じ実体だと検索エンジンが結び付けやすい |
| `/area/katsushika` | 不採用。葛飾区の業者選び・地域の事情を深く説明するページで、「葛飾区 太陽光 業者」の受け持ち。GBP の行き先にすると、事業の入口が2つに割れる。TOP から1クリックで届くので、TOP を入口にして流す |
| `/contact` | 予約・問い合わせの欄に入れる（ウェブサイトの欄には入れない） |

GBP からの訪問を分けて数えたいときは、ウェブサイトの欄の URL に `?utm_source=google&utm_medium=organic&utm_campaign=gbp` を付けてもよい（このサイトの canonical はパラメータの無い URL を指すので、検索の評価は割れない）。ただし、いまサイトにはアクセス解析が入っていないため、付けても数えられない（`docs/seo-playbook.md` の「計測」）。

## 3. GBP の設定（運営者が行う）

- ビジネス名は「SOLAR SHIFT」。地域名やキーワードを名前に足さない（ガイドライン違反になる）
- メインのカテゴリは、実際の事業に合うもの。管理画面のカテゴリ欄に「太陽」と入れて出る候補から、太陽光発電の設置・設備に近いものを選ぶ
- サービス：住宅用太陽光発電／家庭用蓄電池／太陽光＋蓄電池のセット導入／V2H／HEMS／補助金のご相談／現地調査・お見積もり（無料）
- 対応エリア：葛飾区・足立区・江戸川区・墨田区（サイトの「対応エリア」と同じ）
- ビジネスの説明に使える文（サイトに載せている事実だけで書いた。URL・電話番号・「No.1」などの言葉は説明に入れない）：

  > SOLAR SHIFT（ソーラーシフト）は、東京都葛飾区亀有の株式会社サイプレスが運営する、住宅用太陽光発電・家庭用蓄電池の事業です。葛飾区内は全域に対応し、周辺の足立区・江戸川区・墨田区にも伺います。住宅用太陽光発電、家庭用蓄電池、太陽光と蓄電池のセット、V2H、HEMSの導入について、現地調査からお見積もり、補助金の活用のご相談、導入後のご相談まで対応します。現地調査とお見積もりは無料です。葛飾区の「かつしかエコ助成金」と東京都の助成は、申請の順番と期限が制度ごとに違うため、工事の予定日から逆算して計画を立てます。営業時間は9時から20時で、定休日はありません。

- 写真は、実際の事務所・スタッフ・施工の写真だけ（イメージ画像・生成画像を実物のように載せない）
- 口コミは、実際のお客様にお願いする。見返り（割引・謝礼）は出さない。自分で書かない。返信は事実の範囲で
- 投稿（最新情報）は、補助金の受付開始・締切など、サイトの更新履歴に載せた事実と合わせると、内容を作りやすい

## 4. GBP ができたら、サイトに入れるもの

`lib/site.ts` の `gbp` に入れる。入れると、サイトの表示と構造化データに自動で出る。

| 項目 | 入れるもの | 出る場所 |
| --- | --- | --- |
| `mapsUrl` | プロフィールの共有リンク | 「Google マップで見る」のリンク先、LocalBusiness の `sameAs` と `hasMap` |
| `embedUrl` | 「共有 → 地図を埋め込む」の iframe の `src` | 運営会社のページと、エリアのページの地図 |
| `reviewUrl` | 口コミを書くページの URL | いまはどこにも出ない（口コミのお願いの導線を作るときに使う） |

GBP がまだ無い間は、地図のリンクは住所での検索 URL になる（`companyMapUrl()`）。架空の URL は入れない。

## 5. サイトの側で実装していること

- 葛飾区のエリアのページ（`/area/katsushika`）：葛飾区の業者選び・地域の事情（人口・世帯数、水害ハザードマップの浸水想定など、区の公式資料にもとづく）・区の助成への導線
- 周辺の区のページ（`/area/adachi`・`/area/sumida`・`/area/edogawa`）：その区の公式の制度を、葛飾区の説明と混ぜずに載せている（区ごとに制度が違うため）
- 町名ごとのページは作らない（中身が同じページが増えるだけで、評価が下がる）
- 構造化データ：LocalBusiness（所在地・緯度経度・営業時間・対応エリア・提供サービス）、Organization（運営会社）、TOP だけに Brand（SOLAR SHIFT）
- 地域の FAQ は、その地域のページだけに置く（同じ質問を多くのページに並べない。`npm run seo:audit` が数える）

## 6. やらないこと

- 町名・駅名だけを差し替えたページを作る
- GBP の名前にキーワードを足す、住所の無い場所をプロフィールにする
- 口コミの依頼に見返りを出す、自作の口コミ、ほかのサイトの口コミの転載
- 構造化データに Review・AggregateRating を出す（掲載の許可を得た実際の声が揃うまで出さない）
