# サイトの外で行う SEO の作業一覧

コードでは実施できない作業をまとめる。どれも、運営者（株式会社サイプレス）の側で行うもの。
上から順に優先する（会社と事業の結び付きを先に固め、地域、SNS、取引先、地域団体、業界団体の順）。

最終確認：2026-11-04

## やらないこと

- リンクを買わない（有料の被リンク、相互リンクの募集サービス、記事の掲載料を払ってリンクをもらうことを含む）
- 質の低いディレクトリ・リンク集への大量登録をしない
- 自分で口コミを書かない。口コミの見返りに、割引や謝礼を出さない
- 実在しない SNS やプロフィールの URL を、サイトの構造化データ（`sameAs`）に入れない
- ほかのサイトに、同じ文章を大量に配らない（プレスリリースの配信サービスに、記事を丸ごと流すことを含む）

## 1. 株式会社サイプレスの公式サイトからの、事業としてのリンク

**状態：済み（2026-11-04 に確認）。** 運営会社のサイト（`https://www.cypress-all.co.jp/`）の事業の一覧に「太陽光事業」として `https://www.solarshift.jp/` へのリンクがあり、構造化データにも「SOLAR SHIFT（株式会社サイプレス 太陽光事業）」として載っている。所在地の表記も同じ（〒125-0061 東京都葛飾区亀有3-16-14-201）。

残っている改善（任意）：

- [ ] リンクの文言を、事業の内容が分かるものにする。いまは「太陽光事業」。例：「太陽光発電・蓄電池事業 SOLAR SHIFT」
- SOLAR SHIFT の側は、すでに運営会社へリンクしている（フッター・運営会社のページ・構造化データの `sameAs`）

## 2. Google ビジネス プロフィール

地域の検索（「葛飾区 太陽光 業者」など）と地図の検索で、いちばん効く。設定の中身・ウェブサイトの欄に入れる URL・説明文は `docs/local-seo.md`。

- [ ] プロフィールを作る（ビジネス名は「SOLAR SHIFT」）
- [ ] 所在地・電話・営業時間を、サイトと一字一句そろえる（`docs/local-seo.md` の表）
- [ ] ウェブサイトの欄に `https://www.solarshift.jp/`、予約・問い合わせの欄に `https://www.solarshift.jp/contact`
- [ ] 登録が済んだら、`lib/site.ts` の `gbp`（`mapsUrl`・`embedUrl`・`reviewUrl`）に URL を入れる

## 3. 公式の SNS プロフィール

実際に運用するものだけを作る。作っただけで更新しないアカウントは、置かないほうがよい。

- [ ] Instagram・X・YouTube などを始める場合は、プロフィールの URL 欄に `https://www.solarshift.jp/` を入れる
- [ ] アカウントができたら、`lib/site.ts` の `social` に URL を入れる（構造化データの `sameAs` に出る）
- [ ] 名称・所在地・電話の表記を、サイトとそろえる
- 載せる内容の例：補助金の受付開始・締切（サイトの更新履歴に載せた事実）、実際の施工（お客様の掲載許可を得たもの）

## 4. メーカー・施工パートナーからの掲載

依頼して張ってもらうリンクではなく、実際の取引にもとづく掲載だけを対象にする。

- [ ] 取扱メーカーの「販売店・施工店の検索」に載せられる場合は、掲載を申請する（載せる条件は、メーカーごとに違う。条件を満たさないのに「認定」「正規」と名乗らない）
- [ ] 施工を担当する会社が、サイトで取引先を紹介している場合は、SOLAR SHIFT の掲載を相談する

## 5. 地域の団体

- [ ] 葛飾区内の商工会議所・商店会など、実際に加入している団体の会員紹介に載せる
- [ ] 地域の催し・勉強会などに協力したときは、主催者の告知に URL を載せてもらう

## 6. 業界団体

- [ ] 実際に加入している業界団体があれば、会員一覧への掲載を確かめる（加入していない団体の名前を、サイトに書かない）

どの掲載でも、名称・所在地・電話の表記をサイトとそろえる（`docs/local-seo.md`）。

## 7. 取り上げてもらえる材料（デジタル PR の候補）

サイトにすでにある、ほかでは読めない材料。地域の媒体や、区内の団体の会報に紹介を相談するときに使える。中身は一次情報だけなので、そのまま渡してよい。

| 材料 | ページ | 何が独自か |
| --- | --- | --- |
| かつしかエコ助成金の事前協議の期限チェッカー | `/subsidy/katsushika` | 工事の予定日から、事前協議書を出す目安の日を出す（区の案内の「原則4週間前」にもとづく） |
| 葛飾区・東京都・国の補助金の比較表と更新履歴 | `/subsidy` | 3つの制度を同じ項目で並べ、制度の変更と確認日を残している |
| 補助金シミュレーター | `/simulation` | 区と都の金額を合算せずに、制度ごとに出す |
| 葛飾区の水害と、蓄電池の置き場所 | `/area/katsushika`・`/guide/blackout` | 区のハザードマップにもとづく |

紹介をお願いするときに、記事の掲載料・リンクの対価を払わない。

## 8. Search Console・Bing Webmaster Tools

- Search Console：DNS の TXT レコードで確認済み。サイトマップ（`https://www.solarshift.jp/sitemap.xml`）とブログの RSS（`https://www.solarshift.jp/feed.xml`）を送る。手順と、定期的に見る項目は `docs/seo-search-console.md`
- [ ] Bing Webmaster Tools に登録する（Search Console から取り込める。確認コードは環境変数 `BING_SITE_VERIFICATION`）
- IndexNow：本番デプロイのたびに、変更したページの URL を Bing などへ送っている（`.github/workflows/indexnow.yml`）。Google はこれを使わないので、Google の順位の施策ではない

## 9. サイトに入れると効く、運営者からの情報

サイトの外の作業ではないが、運営者からの情報が無いと入れられないもの。

- [ ] 施工事例の写真（実際の施工の写真）と、施工した年月
- [ ] 施工体制（だれが施工するか）・保証・工事保険・資格。書面で確認できたものだけを `lib/site.ts` の `trust` に入れる
- [ ] 年末年始の休み
- [ ] LINE の公式アカウント（始める場合）
