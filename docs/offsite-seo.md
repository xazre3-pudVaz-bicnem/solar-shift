# サイトの外で行う SEO の作業一覧

コードでは実施できない作業をまとめる。どれも、運営者（株式会社サイプレス）の側で行うもの。
上から順に、検索順位への効き目が大きい。

## やらないこと

- リンクを買わない（有料の被リンク、相互リンクの募集サービス、記事の掲載料を払ってリンクをもらうことを含む）
- 質の低いディレクトリ・リンク集への大量登録をしない
- 自分で口コミを書かない。口コミの見返りに、割引や謝礼を出さない
- 実在しない SNS やプロフィールの URL を、サイトの構造化データ（`sameAs`）に入れない

## 1. Google ビジネス プロフィール

地域の検索（「葛飾区 太陽光 業者」など）と地図の検索で、いちばん効く。

- [ ] プロフィールを作る（ビジネス名は「SOLAR SHIFT」。運営会社名を名前に足さない）
- [ ] 所在地・電話・営業時間を、サイトと一字一句そろえる
  - 所在地：〒125-0061 東京都葛飾区亀有3丁目16-14
  - 電話：090-2360-0052
  - 営業時間：9:00〜20:00（定休日なし）。年末年始の休みがあれば、特別営業時間に入れる
- [ ] ウェブサイトの欄に `https://www.solarshift.jp/` を入れる
- [ ] カテゴリは、実際の事業に合うものを選ぶ（太陽光発電の設置に関するカテゴリ）
- [ ] 対応エリア（葛飾区・足立区・江戸川区・墨田区）を設定する
- [ ] 写真は、実際の事務所・スタッフ・施工の写真だけを載せる（イメージ画像や生成画像を、実物のように載せない）
- [ ] 口コミは、実際のお客様にお願いする。返信は、事実の範囲で丁寧に
- [ ] 登録が済んだら、サイトの側に次を入れる（`lib/site.ts` の `gbp`）
  - `mapsUrl` … プロフィールの共有リンク
  - `embedUrl` … 「共有 → 地図を埋め込む」の iframe の `src`（入れると、運営会社のページと葛飾区のエリアのページに地図が出る）
  - `reviewUrl` … 口コミを書くページの URL
  - これらを入れると、構造化データの `sameAs` と `hasMap` にも反映される

## 2. 株式会社サイプレスの公式サイトからのリンク

運営会社のサイト（https://cypress-all.co.jp/）から SOLAR SHIFT へリンクを張ると、会社と事業の関係が検索エンジンに伝わる。

- [ ] 事業内容・サービスの一覧に「太陽光発電・蓄電池事業 SOLAR SHIFT」を載せ、`https://www.solarshift.jp/` へリンクする
- [ ] リンクの文言は「太陽光発電・蓄電池事業 SOLAR SHIFT」のように、事業の内容が分かるものにする（「こちら」だけにしない）
- [ ] 会社概要の所在地を、SOLAR SHIFT のサイトとそろえる
  - いま、会社のサイトは「葛飾区白鳥4-6-1-623」、SOLAR SHIFT は「葛飾区亀有3丁目16-14」。どちらが正しいかを決めて、両方をそろえる
- SOLAR SHIFT の側は、すでに運営会社へのリンクを置いている（フッター・運営会社のページ・構造化データの `sameAs`）

## 3. Google Search Console・Bing Webmaster Tools

- [ ] Search Console に登録し、サイトマップ（`https://www.solarshift.jp/sitemap.xml`）を送る
- [ ] Bing Webmaster Tools に登録する（ChatGPT の検索は Bing の索引を使う）
- 手順と、定期的に見る項目は `docs/seo-search-console.md`

## 4. 公式の SNS プロフィール

実際に運用するものだけを作る。作っただけで更新しないアカウントは、置かないほうがよい。

- [ ] Instagram・X・YouTube などを始める場合は、プロフィールの URL 欄に `https://www.solarshift.jp/` を入れる
- [ ] アカウントができたら、`lib/site.ts` の `social` に URL を入れる（構造化データの `sameAs` に出る）
- [ ] 名称・所在地・電話の表記を、サイトとそろえる

## 5. 取引先・地域からの、自然な紹介

依頼して張ってもらうリンクではなく、実際の関係にもとづく掲載だけを対象にする。

- [ ] 取扱メーカーの「販売店・施工店の検索」に載せられる場合は、掲載を申請する（載せる条件は、メーカーごとに違う）
- [ ] 施工を担当する会社がサイトで取引先を紹介している場合は、SOLAR SHIFT の掲載を相談する
- [ ] 葛飾区内の商工会議所・商店会など、実際に加入している団体の会員紹介に載せる
- [ ] 地域の催し・勉強会などに協力したときは、主催者の告知に URL を載せてもらう
- どの掲載でも、名称・所在地・電話の表記をサイトとそろえる

## 6. 名称・所在地・電話の表記をそろえる

検索エンジンは、いろいろな場所に載っている名称・所在地・電話を突き合わせて、同じ事業者かどうかを判断する。

| 項目 | そろえる表記 |
| --- | --- |
| 名称 | SOLAR SHIFT（ソーラーシフト） |
| 運営会社 | 株式会社サイプレス |
| 所在地 | 〒125-0061 東京都葛飾区亀有3丁目16-14 |
| 電話 | 090-2360-0052 |
| URL | https://www.solarshift.jp/ |

サイトの側は `lib/site.ts` の1か所から出している。変えるときは、`lib/site.ts` と `docs/VERIFIED_FACTS.md` を直す。

## 7. サイトに入れると効く、運営者からの情報

サイトの外の作業ではないが、運営者からの情報が無いと入れられないもの。

- [ ] 施工事例の写真（実際の施工の写真）と、施工した年月
- [ ] 施工体制（だれが施工するか）・保証・工事保険・資格。書面で確認できたものだけを `lib/site.ts` の `trust` に入れる
- [ ] 年末年始の休み
- [ ] LINE の公式アカウント（始める場合）
