## 4. 検索結果（SERP）の調べ方と限界

- 使えた検索の道具は、日本の Google の検索結果ではなかった（地域・言語の設定ができない）。そのため、**日本の Google での順位は測っていない**。順位の推測もしていない
- その道具で「葛飾区 太陽光 補助金」などを調べた範囲では、上位は自治体の案内ページ・PDF、補助金のまとめサイト、太陽光の見積もり比較サイト、旅行・生活情報サイトのまとめ記事だった。solarshift.jp は見つからなかった
- 実際の順位・表示回数は、Search Console のデータで見る（`npm run seo:opportunities`）。月に1回、CSV を出して回す（`docs/seo-playbook.md`）

## 5. 今回しなかったこと（理由）

| 項目 | 理由 |
| --- | --- |
| 東京23区の補助金の比較ページ | 23 区すべての公式の制度を確かめて、毎月更新し続ける必要がある。確かめていない区を推測で埋めない。周辺の3区（足立・墨田・江戸川）は、確かめたうえでエリアのページに載せている |
| 自家消費・売電の推計シミュレーター、蓄電池の容量チェック | 一次情報にもとづく計算の前提（日射・使い方の比率など）を出典つきで用意できない。根拠の無い推計の数字を出さない。FIT の段階的な売電単価の計算は、すでに `/guide/solar-payback` にある |
| 新しいページ・地域ページ・記事の追加 | 方針どおり。新しいページを作る条件は `docs/seo-playbook.md` の「4」 |
| アクセス解析・Search Console の確認タグ | 測定 ID・確認コードは運営者が発行するもの。架空の ID を書かない（Search Console は DNS で確認済み） |
